# pybricks-voice

Drive a LEGO robot by talking to it. Whisper runs on the laptop's NPU, and for
now the robot is a simulated SPIKE Prime driving base, drawn from real LEGO
parts and with real physics from [MuJoCo](https://mujoco.org): its wheels can
slip, and it can push the blocks and the ball on its table. So the voice side can be built and tested without
Bluetooth or a real table.

```
"forward 50 centimeters, turn right 90 degrees, then back 20"
  → Whisper on the Hexagon NPU (~150–250 ms)
  → straight(500 mm), turn(90°), straight(-200 mm)
  → the robot drives it
```

Built with [PyWinRT](https://github.com/pywinrt/pywinrt) 4: WinUI 3 for the
window, [pygfx](https://github.com/pygfx/pygfx) for the 3D view, drawn with
D3D12 straight into a XAML `SwapChainPanel`, AudioGraph for the microphone,
and ONNX Runtime's QNN provider for the NPU.

## Requirements

- A Snapdragon X Elite PC (the Whisper model is precompiled for its NPU)
- [uv](https://docs.astral.sh/uv/) and an ARM64 CPython 3.14 (pinned in `.python-version`)
- Visual Studio with the C++ workload and its "C++ Clang tools for Windows", and
  CMake, to build MuJoCo and FreeType once: neither has Windows ARM64 builds

## Setup

```
uv run --no-project tools/get_mujoco.py
uv sync
uv run tools/get_models.py
uv run tools/get_freetype.py
```

`get_mujoco.py` comes first: `uv sync` installs MuJoCo from the wheel it
builds into `vendor/wheels/`.

## Run

```
uv run python -m pybricks_voice
```

Say things like "go forward 30 centimeters", "turn left", "turn around",
"back up 10 inches", "spin right for 2 seconds", "faster", "stop", and chain
them with "then". You can also type commands into the box. In the 3D view, C
switches between the chase camera and the top view, and the scroll wheel zooms.

## macOS

On a Mac, the same app runs in an AppKit window through
[rubicon-objc](https://github.com/beeware/rubicon-objc), with pygfx drawing
into a `CAMetalLayer`. Whisper and the microphone aren't there yet, so
commands are typed. `uv sync` is all the setup; `--screenshot` needs the
Screen Recording permission for the terminal it runs from.

## Check

```
uv run python -m unittest          # robot, grammar, segmenter, physics; tests/windows/ and tests/macos/ on their platforms
uv run tools/check_whisper.py      # Windows speech synthesis -> Whisper on the NPU -> commands
```

## Layout

| | |
|---|---|
| `pybricks_voice/robot.py` | Pybricks `DriveBase`-style commands and their motion profiles: where each wheel should be |
| `pybricks_voice/grammar.py` | what Whisper heard → commands |
| `pybricks_voice/whisper.py` | Whisper's features and a pure-Python token decoder, for every backend |
| `pybricks_voice/speech.py` | voice-activity detection, the Whisper worker thread |
| `pybricks_voice/core.py` | the app, less its window: what every platform's app shares |
| `pybricks_voice/physics.py` | the robot and its table in MuJoCo; its motors follow `robot.py`'s wheel angles |
| `pybricks_voice/scene.py` | the 3D scene, in pygfx |
| `pybricks_voice/ldraw.py` | LEGO models from the LDraw parts library, as triangles |
| `pybricks_voice/models/` | Driving Base 1 as an LDraw model, and the LDraw parts it uses |
| `pybricks_voice/windows/app.py` | the WinUI 3 app |
| `pybricks_voice/windows/main_window.xaml` | the window's layout |
| `pybricks_voice/windows/main_window.py` | its named elements, typed, its events wired to handlers (`py:Click="on_go"`) and properties bound to values (`py:Text="hud_line"`): generated by `tools/xaml_types.py` |
| `pybricks_voice/windows/scene_view.py` | the 3D view in a `SwapChainPanel`, drawn by a thread of its own |
| `pybricks_voice/windows/whisper_qnn.py` | Whisper-Small on the NPU |
| `pybricks_voice/windows/microphone.py` | the microphone, through AudioGraph |
| `pybricks_voice/windows/loop.py` | asyncio as a guest of the UI thread's `DispatcherQueue` |
| `pybricks_voice/macos/app.py` | the AppKit app, its window built in code |
| `pybricks_voice/macos/scene_view.py` | the 3D view in a `CAMetalLayer`, drawn by a thread of its own |
| `pybricks_voice/macos/loop.py` | asyncio as a guest of the main thread's `CFRunLoop` |
| `pybricks_voice/macos/corefoundation.py` | the CoreFoundation calls that needs, declared with ctypes |
| `tools/get_freetype.py` | builds `vendor/freetype.dll` for pygfx |
| `tools/get_mujoco.py` | builds a MuJoCo wheel into `vendor/wheels/` |
| `tools/xaml_types.py` | generates typed classes for the `.xaml` files, with their event wiring, as WinUI's compiler does for C# |
| `tools/get_ldraw.py` | copies the parts the model uses from LDraw's library into `models/ldraw/` |
| `spikes/` | experiments kept for their findings: Composition Scenes, the window-drag stall, LDraw previews |
